# EvalCall 评测报告章节导航验收

- 日期：2026-07-16
- 范围：评测报告模板及五套正式演示报告
- 主验收页：`site-deploy/report-t02-v2.html`

## 阅读路径

评测报告顶部新增六个可点击 Tab，并明确表达从结论到证据的阅读关系：

`报告总览 → 上线门禁 → 根因归属 → 运行审计 → 优化方向 → 逐项证据`

对应决策逻辑为：

`看结果 → 做决策 → 定责任 → 验可信 → 给行动 → 可复核`

## 已实现

1. 点击任意 Tab，页面平滑跳到对应报告章节。
2. 导航在长报告滚动过程中保持吸顶，避免用户失去当前位置。
3. 当前章节 Tab 与下方关系节点同步高亮。
4. 直接访问带章节锚点的 URL 时，能恢复对应选中状态。
5. 移动端改为横向可滑动 Tab；打印报告时自动隐藏交互导航。
6. 功能写入 Jinja 报告模板，后续新生成的报告自动继承，不是单页补丁。
