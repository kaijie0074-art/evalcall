## 站内产物查看器补充验收

- 原问题：JSON 产物以浏览器附件形式下载，主办方电脑未配置默认打开程序时无法现场查看。
- 修复：所有任务包、Checklist、评测数据、归因、优化计划和回归请求默认在 Demo 右侧直接打开。
- 展示内容：文件名、格式、大小、条目数、中文化字段、结构化内容，以及折叠的原始内容。
- 原始下载：降级为“备用：下载原文件”，不再是现场演示的默认动作。
- 实时浏览器验收：新建会话完整跑通六步，实际打开测试任务包、优化计划和同尺回归请求均成功。
- 现场依赖：只依赖 Demo 页面与本地服务，不依赖电脑安装 JSON 编辑器或其他桌面软件。
