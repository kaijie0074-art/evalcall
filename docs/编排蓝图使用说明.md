# 通用编排蓝图

设计系统通过 `design-composition/v1` 蓝图描述一个项目的页面结构。蓝图只负责“页面有什么、区域之间是什么关系”，字体、留白、颜色和组件样式仍由视觉选型系统负责。

## 使用方式

1. 打开 `/evalcall-style-configurator.html`。
2. 在“页面编排与区域关系”中选择内置示例，或导入 JSON 文件。
3. 修改区域、比例、节点和内容。
4. 点击“解析并生成页面”。
5. 继续选择 Linear、Incident.io、Retool 整层视觉系统或逐项修改子元素。
6. 导出最终方案。导出文件会同时包含 `composition_blueprint` 和视觉选择。

可直接从 `site-deploy/sample-assets/编排蓝图_通用模板.json` 开始修改。

## 顶层字段

- `schema`：固定为 `design-composition/v1`。
- `id`、`name`：项目蓝图标识和名称。
- `page`：页面上下文、标题和状态。
- `navigation`：可选的流程或页面导航。
- `layout.direction`：`columns` 或 `rows`。
- `layout.tracks`：每个区域的比例，数量应与 `regions` 一致。
- `layout.gap`：区域间距。
- `regions`：页面区域列表。

## 区域类型

- `stack`：面板纵向组合，适合输入输出、详情与操作。
- `cards`：指标或摘要卡片。
- `table`：表格型工作区。
- `flow`：流程或关系图，支持 `vertical` 与 `horizontal`。
- `form`：字段与操作表单。
- `timeline`：事件、历史或里程碑。

导入失败时，页面会给出具体缺失字段或不支持的区域类型；无效蓝图不会覆盖当前页面。
